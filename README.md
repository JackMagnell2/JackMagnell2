## Hi there 👋

I am currently studying for a master’s in Information Systems at Lund University, with graduation expected in June 2027. I enjoy the combination of business and technology, and learning how the software we build can be useful in practice. Alongside my studies, I work as a lab assistant, helping students with programming tasks and Git/GitHub, as well as grading introductory assignments.

I also recently participated in the SINCE AI Hackathon, where a friend and I worked on a challenge from Turku Energia. We built and hosted a web application for predicting electricity imbalance prices, using a model we trained ourselves. We developed both the frontend and backend, mainly using Python, TypeScript and CSS. You can find the project in the [hackathon repository](https://github.com/ViktorHamberg/SinceAI-Hackathon-Project)!

Besides this project, I have done a lot of work in school, but much of this is in private repositories I cannot make public. Some of that work includes a Formula 1-themed reaction timer that runs as an app with a database behind it, and a flashcard application that lets users create custom decks and study their flashcards. The flashcard app also integrated AI through the OpenAI API, allowing users to create questions and get AI-generated answers. The AI could also grade users’ answers from 0 to 100%. I created a RESTful API for the app as well, which allowed users to manage decks and flashcards from outside the app itself, with tests written using JUnit. We have also built transaction and vehicle management systems for fictional companies.

I previously worked at Energy Opticon, first as a software developer intern and then as a summer software engineer. During the internship, we built a backend prototype for a diagramming tool. During the summer, I worked on both the frontend and backend as the tool was being migrated from desktop to browser. We worked in a Scrum team, and I regularly presented our progress to management and colleagues.

In these projects, I have mainly worked with C#, Java, Python, JavaScript/TypeScript and SQL, alongside HTML, CSS, React and .NET. I also use Git/GitHub regularly and feel comfortable working with it both independently and in a team. My aim is to keep improving and learn more languages and technologies along the way! One of my personal projects is a randomizer website I built and deployed that lets users play around with a bunch of fun tools they might need, such as random selection, team generation and list shuffling. Feel free to check it out on [randomizerkit.com](https://randomizerkit.com/)!
